📧 Python Email Automation Script

Un script Python conçu pour automatiser l'envoi d'e-mails de manière simple, rapide et fiable. Ce projet permet d'envoyer des messages personnalisés à un ou plusieurs destinataires, avec prise en charge des pièces jointes, des modèles de messages et de la configuration SMTP.

🚀 Fonctionnalités
Envoi automatique d'e-mails via SMTP
Gestion de plusieurs destinataires
Personnalisation du sujet et du contenu des messages
Support des pièces jointes
Configuration sécurisée via variables d'environnement
Journalisation des envois et gestion des erreurs
Facile à intégrer dans des workflows d'automatisation
🛠️ Technologies utilisées
Python 3.x
smtplib
email
Variables d'environnement (dotenv recommandé)
📋 Cas d'utilisation
Notifications automatiques
Campagnes d'e-mails internes
Rapports périodiques
Alertes système
Relances et communications automatisées
⚠️ Avertissement

Ce projet est destiné à l'automatisation légitime des communications par e-mail. L'utilisateur est responsable du respect des réglementations en vigueur concernant l'envoi de courriers électroniques et la protection des données.
